## Hair source and leakage audit

No local Hair checkpoint was found. The original `research-assets/new datasets/archive (6)` contains disease-named image files inside mixed DermNet-style folders. The source archive has no patient IDs, verified acquisition metadata, explicit licence record, or independent phone-photo test cohort. The 12 GB `archive....` balanced copy contains many `aug_` derivatives of the same originals and was excluded from validation. `archive (11) analysis tool` repeats original files; it was not treated as an independent source. The `archive (16)/data0330` bald/notbald folders contain stock, hairstyle, hair-loss and dandruff photos mixed under broad labels, so they do not establish a trustworthy healthy-scalp class.

The first controlled subset used filename labels from the original archive only: alopecia areata (104 files), acne keloidalis nuchae (61), scalp psoriasis (109), and tinea capitis/kerion (86). All 360 selected images decoded. SHA-256 deduplication left 357. A conservative 64-bit difference-hash comparison excluded 17 files participating in 19 cross-label near-match pairs. Remaining near-identical files were grouped before the deterministic stratified split: 203 train, 69 validation, 68 test. Counts by class were 56/19/18, 34/12/12, 64/21/21, and 49/17/17 respectively. Patient-safe splitting remains impossible because IDs are absent. The apparent test scores below therefore measure an internal web-image task, not independent clinical or phone-photo validity.

## Nail verification and full-image/ROI comparison

The existing `nail_convnexttiny_research.pth` SHA-256 matched the pinned value `6c58cd98c9368268115d00f6acd6d1f03dba73132eaacd15cbfa9cf9dfb5bf19`. ConvNeXt Tiny loaded strictly. Its ten-class index order matches the [publisher's metric file](https://huggingface.co/shibarashii/nail-disease-detection/blob/661603d35bab2904055d4d4a943bf305b03a59f9/best_models/convnexttiny/evaluation/metrics.json). No stale checkpoint, class-order mismatch, RGB/BGR swap, or accidental test augmentation was found. The publisher did not provide a training transform, so the adapter's ImageNet normalization and center crop remain an assumption.

The available local comparison contains only 17 uniquely hashed web images with filename labels: nine Beau's lines, three clubbing, three koilonychia, and two onychogryphosis. It lacks patient IDs and independent phone-photo ground truth. The existing resize-short-edge-236/center-crop-224 path scored 6/17, balanced accuracy 0.583 and macro F1 0.625 over these four supported labels. Full-frame 224×224 resize scored 5/17, balanced accuracy 0.500 and macro F1 0.575. A centered 78%-width square ROI scored 6/17, balanced accuracy 0.583 and macro F1 0.542. This is not a validated nail detector; a centered crop may discard an off-center nail. None of the changes convincingly wins, so **Nail deployment remains the existing checkpoint and adapter**.

Three supplied Nail teaching files gave different model rankings. A → B → A through the production adapter reproduced identical top predictions, scores, logits, and class order for A, while B differed. This rules out stale request state in that path. The weak 17-image result is consistent with domain shift and/or the undocumented upstream transform; the exact cause is unproven. The original ten-class model's publisher metric is from its own internal 307-image test, so it cannot be compared directly with this four-class local subset.
