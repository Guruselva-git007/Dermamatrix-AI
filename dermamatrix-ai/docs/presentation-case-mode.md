# Presentation-case mode

This opt-in review feature is for the twenty mapped viva images only. It is
not a machine-learning feature. The server calculates SHA-256 over the uploaded
bytes and only matches an unchanged original file in the small source-controlled
fingerprint table. Any different, edited, re-saved, or patient image remains in
the standard image-quality/context workflow and receives no disease label.

The local sibling `../DERMA PRESENTATION/` folder also contains five newer personal
photos without verified teaching labels. They are deliberately not mapped,
trained on, or pushed to Git. They follow the ordinary Skin photo workflow,
even when presentation matching is selected; the result then states that no
exact teaching file matched.

## Use during the review

1. Choose the matching health area.
2. Upload the original supplied file without editing or converting it.
3. Confirm upload consent.
4. Enable **Presentation case matching**.
5. Review the clearly marked pre-labelled teaching scenario, routine/diet
   support, red flags, and treatment topics to discuss with a doctor or
   pharmacist.

The result deliberately says that it is neither AI inference nor a diagnosis.
It provides no medication dose, prescription, disease-risk score, healing claim,
or personal treatment plan.

## Evidence boundaries

The care content is sourced from condition-guide records and is labelled as
education for a clinician/pharmacist discussion. It does not validate the
presentation source image, confirm its original diagnosis, or transfer that
label to a patient. Authoritative reference links appear in the app's condition
guide and include the American Academy of Dermatology resources for acne,
ringworm, psoriasis, seborrheic dermatitis, nail fungus, nail psoriasis, and
seborrheic keratoses.
